Preposição

→ Estabelece conexão entre palavras. Cria diferentes relações de sentido

  • De lugar

    - Moramos EM uma cidade violenta

  • Meio

    - Conversamos POR telefone (conversando por meio do telefone)

  • Compania

    - Irei ao mercado COM você

  • Matéria

    - Um brinco feito DE ouro

  • Assunto

    - Conversamos SOBRE política

  • Oposição

    - Ele agiu CONTRA mim

  • Finalidade

    - Estudei PARA melhorar minha nota

  • Instrumento

    - Fiz a prova À lápis (o lápis foi o instrumento que usou para fazer a prova)

OBS: Uma mesma preposição pode estabelecer diferentes relações semânticas

→ O "de", por exemplo, pode ser de causa (morreu DE fome) / matéria (a caixa é DE madeira) / assunto (falamos DE saúde pública) / posse (educação é um direito DE todos) / origem (ele é de uma boa família) / agente de uma ação (ela foi cercada DE alunos)

OBS 2:

combinação: ao = a + o

contração: no = em + o / pelo = por + o
