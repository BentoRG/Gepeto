Conjuntos

Agrupamentos de elementos, relações e operações

Notação e Relações

Um conjunto é uma coleção de elementos; a ordem e as repetições não importam: {1, 2, 3} = {3, 1, 2, 2}.

Formas de Representar

  • Enumeração: A = {2, 4, 6, 8}
  • Propriedade: A = {x | x é par e 0 < x < 10}
  • Diagrama de Venn: região fechada com os elementos dentro

Símbolos

  1. ∈ / ∉ — pertence / não pertence (elemento × conjunto). Ex.: 2 ∈ A
  2. ⊂ / ⊄ — está contido / não está contido (conjunto × conjunto). Ex.: {2} ⊂ A
  3. ∅ — conjunto vazio, subconjunto de todo conjunto
  4. n(A) — número de elementos (cardinalidade) de A

Erro clássico: pertinência liga elemento a conjunto (2 ∈ A); inclusão liga conjunto a conjunto (A ⊂ B). Um conjunto com n elementos tem 2n subconjuntos.

Operações entre Conjuntos

  • União (A ∪ B): elementos que estão em A ou em B
  • Interseção (A ∩ B): elementos que estão em A e em B. Se A ∩ B = ∅, os conjuntos são disjuntos
  • Diferença (A - B): elementos de A que não estão em B
  • Complementar (AC): o que falta em A para chegar ao universo U (vale se A ⊂ U): AC = U - A

Exemplo

A = {1, 2, 3, 4} e B = {3, 4, 5}

A ∪ B = {1, 2, 3, 4, 5} · A ∩ B = {3, 4}

A - B = {1, 2} · B - A = {5}

n(A ∪ B) = n(A) + n(B) - n(A ∩ B)

A diferença não é comutativa: A - B ≠ B - A. A fórmula acima evita contar duas vezes os elementos da interseção.

Do contar ao medir; a hierarquia dos números

Asteriscos e sinais: R* tira o zero; R+ são os reais ≥ 0; R-* são os reais < 0. Eles aparecem nos domínios de funções.

Problemas com Diagrama de Venn

Estratégia: preencher sempre de dentro para fora — comece pela interseção e depois subtraia.

Em uma turma de 40 alunos, 25 praticam vôlei, 18 praticam basquete e 8 praticam os dois. Quantos não praticam nenhum?

  • Interseção: 8
  • Só vôlei: 25 - 8 = 17 · Só basquete: 18 - 8 = 10
  • Praticam algum: 17 + 8 + 10 = 35
  • Nenhum: 40 - 35 = 5

Noções de Função

Relações em que cada x tem exatamente um y

Definição e Elementos

Uma função f: A → B associa a cada elemento x de A um único elemento y de B. Escrevemos y = f(x).

  1. Domínio D(f): conjunto de partida A — valores de x permitidos
  2. Contradomínio: conjunto de chegada B
  3. Imagem Im(f): valores de y que realmente aparecem (Im ⊂ B)
  4. Raiz (zero): valor de x com f(x) = 0 — onde o gráfico cruza o eixo x

Teste da reta vertical: se alguma reta vertical cruza o gráfico em mais de um ponto, não é função. Para achar o domínio, exclua divisão por zero e raiz de número negativo.

Tipos de Função

  1. Injetora: elementos diferentes têm imagens diferentes (x1 ≠ x2 ⇒ f(x1) ≠ f(x2))
  2. Sobrejetora: Im(f) = contradomínio (ninguém fica sem par)
  3. Bijetora: injetora e sobrejetora ao mesmo tempo — admite função inversa
  4. Crescente / decrescente: x1 < x2 ⇒ f(x1) < f(x2) / f(x1) > f(x2)

Composta e Inversa

  • Composta: (f ° g)(x) = f(g(x)) — aplica g primeiro, depois f
  • Inversa f-1: desfaz f; troque x por y e isole y. Os gráficos são simétricos em relação à reta y = x

f(x) = 2x + 3 → x = 2y + 3 → f-1(x) = (x - 3)/2

Função Afim

f(x) = ax + b, com a e b reais e a ≠ 0

Definição e Coeficientes

Também chamada de função do 1º grau. Seu gráfico é sempre uma reta.

Coeficientes

  • a (coeficiente angular): taxa de variação — quanto y muda para cada 1 unidade de x. a = Δy / Δx
  • b (coeficiente linear): onde a reta corta o eixo y, no ponto (0, b)

Raiz

f(x) = 0 ⇒ x = -b/a

  • a > 0: função crescente
  • a < 0: função decrescente
  • b = 0: função linear (reta passa pela origem)

Estudo do Sinal

f(x) > 0 f(x) = 0 f(x) < 0
a > 0 x > -b/a x = -b/a x < -b/a
a < 0 x < -b/a x = -b/a x > -b/a

O sinal de f é o de a à direita da raiz e o oposto dele à esquerda.

Como Montar a Lei a partir de Dois Pontos

A reta passa por (1, 3) e (3, 7).

  • a = (7 - 3)/(3 - 1) = 2
  • Use um ponto: 3 = 2 · 1 + b ⇒ b = 1
  • Lei: f(x) = 2x + 1

Aplicação Típica

Custo de uma corrida: C(x) = 4 + 2,5x, em que 4 é a bandeirada (valor fixo = b) e 2,5 é o preço por km (taxa = a). Para 10 km: C = 4 + 25 = R$ 29.

Função Quadrática

f(x) = ax2 + bx + c, com a ≠ 0

Raízes e Discriminante

Também chamada de função do 2º grau. Seu gráfico é uma parábola. As raízes vêm da fórmula de Bhaskara:

Δ = b2 - 4ac · x = (-b ± √Δ) / 2a

Discriminante Raízes reais Parábola
Δ > 0 duas, distintas corta o eixo x em 2 pontos
Δ = 0 uma só (dupla) toca o eixo x no vértice
Δ < 0 nenhuma não toca o eixo x

Relações de Girard

soma das raízes: x1 + x2 = -b/a · produto: x1 · x2 = c/a

Vértice, Concavidade e Gráfico

  • a > 0: concavidade para cima — o vértice é o ponto de mínimo
  • a < 0: concavidade para baixo — o vértice é o ponto de máximo
  • c: a parábola corta o eixo y em (0, c)

Vértice

xv = -b/2a · yv = -Δ/4a

Exemplo

F(x) = x2 - 4x + 3

  • Δ = 16 - 12 = 4 → x = (4 ± 2)/2 → x = 1 ou x = 3
  • xv = 2 e yv = -4/4 = -1 → V(2, -1)
  • Im(f) = [-1, +∞)

O eixo de simetria é a reta x = xv; as raízes ficam à mesma distância dele, por isso xv é a média das raízes.

Problemas de Máximo e Mínimo

Um agricultor tem 40 m de tela para cercar um canteiro retangular. Qual a área máxima?

  • Lados x e 20 - x ⇒ A(x) = x(20 - x) = -x2 + 20x
  • a < 0, então há máximo em xv = -20/(-2) = 10
  • Amáx = 10 · 10 = 100 m2 (um quadrado)

Função Exponencial

A variável está no expoente: f(x) = ax, com a > 0 e a ≠ 1

Revisão de Potências

  1. am · an = am+n
  2. am ÷ an = am-n
  3. (am)n = am·n
  4. (a · b)n = an · bn
  5. a-n = 1/an
  6. am/n = n√(am) · a0 = 1

Gráfico e Propriedades

  • Domínio: R · Imagem: R+* = (0, +∞)
  • O gráfico passa sempre por (0, 1), pois a0 = 1
  • Nunca toca o eixo x: ele é assíntota horizontal
  • a > 1: crescente (crescimento exponencial)
  • 0 < a < 1: decrescente (decaimento exponencial)
  • É injetora: ax1 = ax2 ⇒ x1 = x2

Equações e Inequações Exponenciais

Método: Igualar as Bases

2x+1 = 32 → 2x+1 = 25 → x + 1 = 5 → x = 4

Em inequações, a desigualdade mantém o sentido se a > 1 e inverte se 0 < a < 1.

(½)x > ¼ → (½)x > (½)2 → x < 2 (base entre 0 e 1: inverte)

Modelo de Crescimento

Capital com juros compostos: M = C · (1 + i)t. Uma população que dobra a cada hora: P(t) = P0 · 2t.

Logaritmo e Função Logarítmica

O expoente que procuramos: a operação inversa da exponenciação

Definição e Condições de Existência

logb a = x ⇔ a = bx

Lê-se: "logaritmo de b na base a". Em loga b, a é a base e b o logaritmando.

  • Condições: b > 0, a > 0 e a ≠ 1
  • loga 1 = 0 · loga a = 1 · loga ak = k
  • Base 10: log x (decimal) · base e = 2,718: ln x (natural)

log2 8 = 3, pois 23 = 8 · log 1000 = 3 · log3 (1/9) = -2

Propriedades Operatórias

  1. Produto: loga (b · c) = loga b + loga c
  2. Quociente: loga (b/c) = loga b - loga c
  3. Potência: loga bk = k · loga b
  4. Mudança de base: loga b = logc b / logc a

Atenção: log (b + c) não é log b + log c. Não existe regra para o logaritmo de uma soma.

Função Logarítmica

f(x) = loga x, com a > 0 e a ≠ 1. É a inversa da exponencial ax.

  • Domínio: R+* · Imagem: R
  • Passa sempre por (1, 0); o eixo y é assíntota vertical
  • a > 1: crescente · 0 < a < 1: decrescente

Domínio de f(x) = log(x - 2)

x - 2 > 0 ⇒ x > 2 ⇒ D = {x ∈ R | x > 2}

Equação Logarítmica

log2 (x + 1) = 3 ⇒ x + 1 = 23 ⇒ x = 7 (confira: x + 1 = 8 > 0)

Erros Comuns

  1. Confundir ∈ (elemento) com ⊂ (conjunto).
  2. Esquecer o universo ao calcular o complementar.
  3. Em Bhaskara, errar o sinal de b ou de -4ac quando c ou a são negativos.
  4. Esquecer que a quadrática tem vértice: valor máximo/mínimo não está nas raízes.
  5. Pensar que ax pode ser negativa: ax > 0 sempre.
  6. Não verificar a condição de existência (logaritmando > 0) ao resolver equação logarítmica.
  7. Não inverter a desigualdade com base entre 0 e 1.
  8. Usar log (b + c) = log b + log c — essa regra não existe.

Checklist de Estudo

  • Sei representar conjuntos e calcular união, interseção, diferença e complementar.
  • Sei passar entre intervalo, desigualdade e reta numérica.
  • Sei montar a lei de uma função afim por dois pontos.
  • Sei achar raízes, vértice e valor máximo/mínimo de uma quadrática.
  • Sei igualar bases em equações exponenciais.
  • Sei aplicar as propriedades de logaritmo e conferir a condição de existência.
